# Montralog

**Monitoring · Tracing · Logging · Tracking**

Open-source, self-hosted observability for understanding your infrastructure and applications. Bring logs, traces, recurring patterns, Prometheus metrics, dashboards and alerts into one workspace.

### Start here

- **[Get the code and run Montralog](https://github.com/montralog/montralog#quickstart)**
- [Read the documentation](https://github.com/montralog/montralog/tree/main/docs)
- [Try the evaluation walkthrough](https://github.com/montralog/montralog/blob/main/docs/EVALUATION.md)
- [Report a bug or contribute](https://github.com/montralog/montralog/blob/main/CONTRIBUTING.md)

### Built for self-hosting

Docker Compose and Helm deployments. SQLite by default, optional PostgreSQL, and Prometheus for metrics. Create dashboards with graphs, stats, tables and timelines; manage scoped API tokens, notification rules, teams and groups.

Company-login configuration supports Microsoft Entra ID, Google Workspace and Okta. Your provider registration and live verification are required. Company login is separate from audit-event collection; vendor audit polling and directory synchronization are not implemented in the current preview.

### Project status

**0.5.0-rc1 is a public preview for evaluation and controlled pilots.** It is not an independently audited production platform. See the [readiness checklist](https://github.com/montralog/montralog/blob/main/docs/PRODUCTION.md) and [verification evidence](https://github.com/montralog/montralog/blob/main/docs/VERIFICATION.md) before relying on it.

First-party code is [Apache-2.0](https://github.com/montralog/montralog/blob/main/LICENSE). Contributions and reproducible feedback are welcome. Please [report security issues privately](https://github.com/montralog/montralog/security/advisories/new).
